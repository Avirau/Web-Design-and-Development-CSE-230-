# Personal Portfolio

A single-page personal portfolio built with semantic HTML5 and an external CSS3 stylesheet (Flexbox/Grid, responsive down to mobile).

## Files
- `index.html` — page structure and content
- `style.css` — all styling (colors, typography, layout, media queries)
- `images/profile.png` — profile photo

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deploy on GitHub Pages
1. Create a new **public** repository on GitHub.
2. Push these files to the repository's default branch (e.g. `main`).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder, then **Save**.
6. Wait a minute or two, then open the URL GitHub shows
   (`https://avirau.github.io/Web-Design-and-Development-CSE-230-/`).
